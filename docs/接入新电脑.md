# 接入一台新电脑（3 分钟）

> 指挥端地址：**http://192.168.16.8:7800**
> 面板口令：`majunjie123`（只有你自己用）
> 登记钥匙：`vOHTVVZk8mnR`（已打在安装包里，不用告诉别人）

---

## 方法 A：发一句话给同事（最快，推荐）

让他在**自己的电脑**上打开 PowerShell（开始菜单搜 `PowerShell`），把这一行粘进去回车：

```powershell
irm http://192.168.16.8:7800/join | iex
```

会发生什么：

1. 下载 33MB 安装包（10 秒左右）
2. 解压到 `C:\Users\<他>\AppData\Local\DSH Fleet`
3. 自动向指挥端登记，领一个只属于这台机器的令牌
4. 写入 `HKCU\...\Run\DSHFleet`（登录自启，**不需要管理员**）
5. 立刻启动代理

**他不需要点“是”，也不会弹 UAC**（除非公司策略禁了 PowerShell）。

---

## 方法 B：拷一个 exe 过去（他不想碰命令行时）

1. 把 `F:\dsh-fleet\被控端\dist\DSH-Fleet-Lite-Setup.exe`（33MB）发给他（微信/共享盘/U盘）
2. 让他**双击** → 下一步 → 安装 → 完成
3. 装完自动登记、自动启动

---

## 装完你这边做什么

1. 打开 Harness →「远程机器」（或浏览器开 `http://127.0.0.1:7800/`）
2. 列表里会多出一台机器，名字默认是**计算机名**
3. **双击机器名改备注**：改成“张伟-前台”“李娜-财务”这种，以后好找
4. 选中它 → 输入框写人话 → 发送

第一次发一句 `hostname` 验证：3～5 秒内应该回显那台机器的主机名。

## 权限说明（很重要）

| 装法 | 权限 | 能做什么 |
| --- | --- | --- |
| 方法 A / B（默认，用户模式） | 普通用户 | 该用户的文件/软件/设置、清他的临时目录、装用户级软件 |
| 管理员运行 `install.ps1 -Mode system` | SYSTEM | 整机：服务、驱动、其他用户目录、改系统设置 |

大多数“帮忙修电脑”的场景用户模式就够。要装到 Program Files、改系统服务，才需要 SYSTEM（那时他得点 UAC）。

## 常见问题

**1. 同事那儿连不上指挥端**
他必须能访问 `192.168.16.8:7800`。同一局域网一般没问题；跨网段/在家办公需要 VPN 或端口映射。

**2. 提示“解压失败”或下载不动**
公司安全软件拦了 PowerShell 下载。改用方法 B（exe 拷过去双击）。

**3. 装完列表里没出现**
- 等 15 秒（心跳周期）
- 让他看 `%LOCALAPPDATA%\DSH Fleet\fleet\logs\agent.log` 最后几行
- 常见原因：登记钥匙过期（我在 `server\data\enroll-key.txt` 里换过 key，但安装包还是旧的 → 重新打包）

**4. 他换电脑/重装系统了**
重新走一遍 A 或 B，会生成新的机器条目；旧的那条右键删掉（面板里 `X` 按钮）。

**5. 怎么卸载**
```powershell
powershell -File "$env:LOCALAPPDATA\DSH Fleet\fleet\uninstall.ps1" -RemoveApp
```
或者你在面板里点那台机器的 `X`（远程自毁）。

## 一次性临时协助（不长期装）

如果只是这一次帮忙，装完用完可以立刻卸：

1. 走方法 A/B 接入
2. 帮完 → 面板点该机器的 `X`（远程自毁：删任务 + 删目录）
3. 或者他自己跑上面那条卸载命令

> 注意：远程自毁只删程序，不删 `HKCU` 的 Run 键残留，卸载脚本才会清干净。

## 当前网络前提

- 指挥端跑在 `192.168.16.8:7800`（你这台机器）
- 同事必须在同一网段，或能通过 VPN 访问这个地址
- 你的 Windows 防火墙：**专用网络**要放行 7800（公用网络默认可能被拦）
