# 使用说明

面向日常使用：怎么打开、怎么用、怎么给别人装、出问题怎么查。

---

## 一、第一次用（三步）

```
1. 双击  F:\dsh-fleet\主控端\tools\设置APIKey.cmd   → 粘 DeepSeek Key
2. 双击  F:\dsh-fleet\主控端\启动指挥端.cmd          → 起服务（也可只靠插件自动拉起）
3. 打开 Harness → 左下角「● 远程机器」
```

口令在 `主控端\data\password.txt`（首次启动自动生成）。

---

## 二、插件面板怎么用

**入口**：Harness 窗口**左下角**的胶囊按钮 `● 远程机器`。

| 圆点颜色 | 含义 |
| --- | --- |
| 🟢 绿 | 已连接，有机器空闲 |
| 🟡 黄 | 已连接，但机器在忙/排队 |
| ⚪ 灰 | 没登录，或所有机器离线 |

**面板结构**（点按钮后从下方弹出）：

```
┌──────────────────────────────┐
│ 远程机器        1/1 在线    ✕ │
├──────────────────────────────┤
│ ● zyf                       │  ← 点一下选中
│   DX\SYSTEM        644G      │
├──────────────────────────────┤
│ 你：看看 C 盘哪些目录最占空间   │
│  ✓ Get-PSDrive C …           │
│  ✓ Get-ChildItem …           │
│  ▸ 执行中 …                   │
│  结论：C 盘用了 309G…          │
├──────────────────────────────┤
│ [对 zyf 说…            ] (↑) │
└──────────────────────────────┘
```

- **发送**：`Enter` 或点 `↑`
- **换行**：`Shift + Enter`
- **停止**：运行中按钮变成 `■`，点一下**立刻杀掉对端进程**（不是等超时）
- **历史**：选中机器时自动带出最近 10 条对话
- **改名**：双击机器名，改成"张伟-前台"这种好认的名字

## 三、能干什么（直接说人话）

| 你说 | 它会 |
| --- | --- |
| 看看 C 盘哪个目录最占空间 | 查磁盘 → 分层扫目录 → 给结论 |
| 清一下临时目录，告诉我释放了多少 | 先测大小 → 清理 → 报数字 |
| 这台机器装了什么软件 | 查注册表卸载项 → 列表 |
| 现在什么程序吃内存最多 | 拉进程 → 排序 → 前 10 |
| 帮我截屏 | 截整屏，直接显示在面板里 |
| 把 C:\Users\Public\a.txt 给我 | 取回文件 |
| 这台机器开机多久了、什么系统 | 查系统信息 |

**注意**：命令是 AI 现场决定的，你看到每一步命令和输出，不满意可以随时停。

## 四、给别人装（每台 1 分钟）

### 方式 A：一行命令（推荐，免管理员）

让对方打开 PowerShell，粘这一行：

```powershell
irm http://<主控端IP>:7800/join | iex
```

它会：下载 33MB → 装到 `%LOCALAPPDATA%\DSH Fleet` → 自动登记拿令牌 → 写登录自启 → 启动。

**不用填任何东西，也不弹 UAC。**

### 方式 B：安装包

把 `F:\dsh-fleet\被控端\dist\DSH-Fleet-Lite-Setup.exe` 发过去，双击 → 下一步 → 完成。

### 装完确认

你这边 15 秒内出现新机器；发一句 `hostname`，3 秒内回显对方主机名就通了。

## 五、配置在哪

| 要改什么 | 改哪 |
| --- | --- |
| 模型 Key | `主控端\upstream-key.txt` 或双击 `tools\设置APIKey.cmd` |
| 控制台口令 | `主控端\data\password.txt`（改完重启服务） |
| 端口 | 环境变量 `FLEET_PORT` |
| 主控端地址（被控端侧） | 重新打包时传 `-ControlUrl`，或改对方 `fleet.json` 的 `control` |
| 换模型 | 环境变量 `AI_MODEL`（默认 `deepseek-chat`） |

## 六、常见问题

| 现象 | 处理 |
| --- | --- |
| 左下角没有「远程机器」 | ① Harness 完全退出再启动（不是关窗口）② 按 `Ctrl+Shift+I` 看 Console 有没有 `[dsh-fleet] 挂载失败` |
| 点开让输口令 | 正常，第一次要输；之后 60 天免输（会话落盘） |
| 机器列表是空的 | 服务没起或被控端没接入：浏览器开 `http://127.0.0.1:7800/` 看是否 200 |
| 黄点 + 排队数字一直涨 | 对端有长命令占着并发槽：面板点 ■，或到那台机器杀掉 `powershell.exe` |
| 发指令没反应 | 同上；也可能对端离线（灰点） |
| 中文乱码 | 新代理已强制 UTF-8；老代理需在面板点 `↻` 推送更新 |
| 打包失败 | `build.ps1` 的 BOM 丢了，用记事本另存为「UTF-8 带 BOM」 |

## 七、卸载

**远程卸**：面板/网页里点那台机器的 `X`（删任务 + 删目录）。

**本机卸**：

```powershell
# 用户模式
powershell -File "$env:LOCALAPPDATA\DSH Fleet\fleet\uninstall.ps1" -RemoveApp

# SYSTEM 模式
powershell -File "C:\Program Files\DSH Fleet\fleet\uninstall.ps1" -RemoveApp
```

**卸插件**（只移除面板，不动主控端和被控端）：

```powershell
$p='F:\dsh-workspace\dsh-home\profiles\desktop'
Copy-Item "$p\package.json.before-install" "$p\package.json" -Force
Copy-Item "$p\cordis.patch.yml.before-install" "$p\cordis.patch.yml" -Force
Remove-Item "$p\node_modules\dsh-fleet-plugin" -Recurse -Force
```

## 八、日常维护

| 事 | 命令 |
| --- | --- |
| 看服务在不在 | `Get-NetTCPConnection -LocalPort 7800 -State Listen` |
| 看服务日志 | `Get-Content 主控端\server.out.log -Tail 20` |
| 看某台被控端日志 | 对方 `%LOCALAPPDATA%\DSH Fleet\fleet\logs\agent.log` |
| 重启服务 | 双击 `主控端\启动指挥端.cmd`（已在跑会直接开面板） |
| 清历史任务 | 删 `主控端\data\tasks\`（超过 2000 条也会自动清） |
| 强制重新登录 | 删 `主控端\data\sessions.json` 后重启服务 |
